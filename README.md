# Модель 1 — GitHub Pages (HtmlCAD)

Эта папка полностью готова для публикации на **GitHub Pages** и адаптирована для просмотра на **телефоне и ПК** в полноэкранном режиме без лишних панелей браузера.
3D-модель автоматически разбита на **5 часть(ей)** (каждый файл не превышает **4 МБ**, что ниже лимита веб-загрузки GitHub в 25 МБ) и при открытии страницы автоматически собирается обратно в единую 3D-сцену.

## Как опубликовать на GitHub Pages за 1 минуту

1. Создайте новый публичный репозиторий на [GitHub](https://github.com/new).
2. Перетащите **все файлы из этой папки** (`index.html`, `404.html`, `model-*.json`, `manifest.webmanifest`, `sw.js`, `icon.svg`, `.nojekyll`, `README.md`) в корень репозитория (**Add file → Upload files → Commit changes**).
3. Перейдите в репозитории во вкладку **Settings → Pages**.
4. В разделе **Build and deployment → Branch** выберите ветку **`main`** (папка **`/ (root)`**) и нажмите **Save**.
5. Через 30–60 секунд появится ссылка вида `https://ваш-логин.github.io/имя-репозитория/` — её можно вставлять в описание под видео на YouTube, в Telegram или на любой сайт!
